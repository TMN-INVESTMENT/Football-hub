# Football Canvas Hub – Betting Platform

Football Canvas Hub is a modern, feature‑rich football betting platform where users can predict match outcomes, place bets, manage their wallet, refer friends, and interact with support in real time. Administrators have full control over matches, user management, and financial transactions.

---

🚀 Features

👤 User Features

· User Authentication – Sign up / log in with email and password (optional admin email detection).
· Dashboard – Overview of balance, recent activity, and quick actions.
· Betting System
  · Single bets on upcoming matches (Home Win, Draw, Away Win).
  · VIP Multi‑bets (combine multiple selections; limits based on user balance).
  · Custom odds percentages for each outcome.
· Wallet Management
  · Deposit funds via mobile money or bank transfer.
  · Withdraw winnings (15% fee) to registered bank/mobile accounts.
  · Transaction history with status (pending, approved, rejected).
· Referral Program – Earn 10% commission on the first deposit of referred friends.
· Support Chat – Real‑time conversation with admin support.
· Profile & Settings – Update personal info, change password, set preferences.
· Announcements – Live slideshow with match previews and general news.
